# AI and read tools

The official Gemini adapter validates structured output, bounds retries/deadlines and produces normalized 768-dimensional embeddings. Five concrete read tools bind every request to verified workspace, ticket and customer context; canonical hashes and current source validation prevent invented evidence. No model write tool or arbitrary SQL/HTTP access exists. Provider availability and accuracy need key-backed verification.
