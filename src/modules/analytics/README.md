# Essential reporting

Authorized overview, issue-category and AI-operation aggregates derive from actual workspace rows. Date ranges default to 30 days and cap at 366. Counts and approval rates are operational metrics; measured model accuracy stays null. Advanced analytics are deferred.

See the [core setup and recovery guide](../../../docs/backend-core-setup.md),
[verification evidence](../../../docs/backend-core-verification.md) and
[solo backend roadmap](../../../docs/solo-backend-steps.md). Historical A/B/C/D
labels are module boundaries under solo execution; only Lead Jira items are updated.
